- **1ère Amendment** : Possession de livres = LÉGAL
- Fabrication explosifs/drogues = ILLÉGAL
- Lockpicking tools = LÉGAL (sauf si intention criminelle)

### 🇫🇷 France
- Possession documentation = LÉGAL (liberté d'expression)
- Fabrication armes/explosifs = ILLÉGAL
- Crochetage = LÉGAL (sur vos propres serrures)

- Possession de certains manuels = ILLÉGAL (Terrorism Act 2000)
- ⚠️ Anarchist Cookbook peut être problématique

- Similaire USA, plutôt permissif

### 🇩🇪 Germany
- Strict sur explosifs et armes
- Documentation médicale OK
